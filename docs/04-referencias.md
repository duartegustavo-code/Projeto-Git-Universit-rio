## Git & GitHub

* **[Documentação Oficial do Git](https://git-scm.com/doc):** Manual de referência completo com explicações detalhadas de todos os comandos.
* **[GitHub Skills](https://skills.github.com/):** Cursos interativos e gratuitos criados pelo próprio GitHub para aprender o fluxo de trabalho colaborativo.
* **[Oh My Git!](https://ohmygit.org/):** Jogo de código aberto para aprender os conceitos de branches, commits e merges de forma visual.
