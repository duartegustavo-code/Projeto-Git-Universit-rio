# Exemplo Prático : Página de Receita Simples

Neste segundo desafio, você vai praticar a estruturação de listas e a aplicação de estilos CSS criando uma página web para exibir uma receita.


### 1. Estrutura e Estilo (HTML & CSS)
Crie um arquivo chamado `receita.html` e estilize-o usando o seu `style.css`:
* Um título principal (`<h1>`) com o nome da receita.
* Uma breve introdução em um parágrafo (`<p>`).
* Um subtítulo (`<h2>`) **"Ingredientes"** seguido por uma **lista não ordenada** (`<ul>`).
* Um subtítulo (`<h2>`) **"Modo de Preparo"** seguido por uma **lista ordenada** (`<ol>`).
* Estilização via CSS:
  * Defina a largura máxima do conteúdo para centralizá-lo na tela.
  * Adicione bordas ou cores de fundo distintas para destacar os títulos.

## Passo a Passo no Git (Fluxo de Trabalho)

 ## 1. Crie uma nova branch para esta funcionalidade:
 ```bash```
   git switch -c feature/exercicio-receita

   
## 2. Crie o arquivo receita.html e atualize o style.css.

 ## 3. Adicione e faça o commit das alterações:

**git add .** 

**git commit -m "feat: adiciona pagina de receita com listas e estilos"**

 ## 4. Envie a branch para o GitHub:

```Bash```

**git push origin feature/exercicio-receita**

**Abra um Pull Request (PR) para juntar as alterações na branch main.**
