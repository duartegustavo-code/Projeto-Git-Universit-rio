# HTML e CSS para iniciantes

## Objetivo:
## Instruir programadores iniciantes para construir sua primeira página web, utilizando linguagem de marcação HTML e estilização CSS

# Público-Alvo:
## Estudantes iniciais na área de programação

# Pré-requisitos
## Ter o VS Code instalado na máquina, ou qualquer outro programa que possa construis o código e seja capaz de mostrá-lo em um navegador

# Tutorial

## Passo 1: Download do Instalador

* Acesse o site oficial: code.visualstudio.com.

* Clique no botão Download for Windows para baixar o executável (arquivo .exe).

## Passo 2: Execução do Instalador

* Localize o arquivo baixado (geralmente em Downloads) e dê um duplo clique para abrir.

* Aceite os termos da licença e clique em Avançar.

* Mantenha o local de instalação padrão e clique em Avançar.

## Passo 3: Configurações Recomendadas

* Na tela de seleção de tarefas adicionais, marque as seguintes opções para facilitar o uso no dia a dia:

* [x] Criar um atalho na Área de Trabalho (opcional)

* [x] Adicionar a ação "Abrir com Code" ao menu de contexto do Explorer para arquivos

* [x] Adicionar a ação "Abrir com Code" ao menu de contexto do Explorer para diretórios

* [x] Adicionar ao PATH (disponível após reiniciar)

* Clique em Avançar e depois em Instalar.

## Passo 4: Conclusão

* Quando a instalação terminar, clique em Concluir com a opção Iniciar o Visual Studio Code marcada.

* Com o editor aberto, você pode traduzir a interface para o português:

* Pressione Ctrl + Shift + X para abrir a aba de Extensões.

* Busque por Brazilian Portuguese Language Pack.

* Clique em Install e, ao final, selecione a opção de reiniciar o programa.
